# AI Security Engineer

**Role family:** cybersecurity · application security · AI system security

## What the role does

Protects AI-enabled products, models, data, and infrastructure. Depending on the organization, the work can combine established application or cloud security with evaluation of threats specific to machine-learning systems.

## Common responsibilities to verify in postings

- Secure APIs, cloud systems, data pipelines, and model-serving infrastructure.
- Assess access controls, data handling, and third-party model integrations.
- Test for misuse, prompt injection, data exposure, or model-specific weaknesses.
- Work with engineering teams to prioritize and fix security findings.
- Document threats and monitor incidents.

## Skills to investigate

Security fundamentals, networking, cloud and application security, scripting, threat modeling, and familiarity with AI systems. Many roles build on prior security engineering experience.

## Career routes

IT support, systems administration, software engineering, or security analyst roles can build a foundation toward security engineering. Hands-on labs and documented projects can demonstrate practical skills.

## Growth context

BLS projects U.S. information security analyst employment to grow **28.5% from 2024 to 2034**. That category is broader than AI security, so the figure should not be presented as an AI-security-specific forecast.
