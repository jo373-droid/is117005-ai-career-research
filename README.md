# IS 117-005 AI Career Research Portfolio

A VitePress research portfolio exploring new job titles, job descriptions, and career options in fast-growing areas of artificial intelligence and technology.

## Live site

**GitHub Pages:** https://jo373-droid.github.io/is117005-ai-career-research/

## Topics

- AI and machine-learning specialists
- Data scientists
- AI product managers
- AI governance analysts
- AI security engineers
- Skills, responsibilities, and career entry routes
- A dated NY / NJ job posting sample from internships through senior roles

## Local development

```sh
npm install
npm run dev
```

Build the site with `npm run build`.

## Publishing

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the VitePress site and deploys it to GitHub Pages on pushes to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

## Research standards

The site distinguishes government employment projections, employer survey expectations, and job-posting evidence. Each finding should be interpreted in its geography and timeframe. See the [research overview](docs/research/index.md) and [NY / NJ job market snapshot](docs/research/job-market-snapshot.md) for sources, role examples, and method.
